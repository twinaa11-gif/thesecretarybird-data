# The SecretaryBird — Public Directory CDN Data

Static JSON feeds powering client-side hydration for [The SecretaryBird](https://www.thesecretarybird.com/) global medical travel directory.

## Endpoints
- `hospitals.json` — Accredited hospitals & partner recovery stays (17 locales)
- `doctors.json` — Specialist surgeons & clinical profiles (17 locales)
- `costs.json` — Standardized procedure packages & recovery timelines (17 locales)

## Security & Privacy Notice
Contains public institutional directory metadata only. Zero patient health information (PHI), internal audit notes, or private triage contact lists are stored in this repository.
